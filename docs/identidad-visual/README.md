## Reglas rápidas de uso

- No confundir el **App Icon** con el **logo horizontal** ni añadir el wordmark dentro del icono cuadrado.
- No estirar, inclinar, recolorear ni aplicar sombras pesadas sobre los logotipos.
- Para fondos oscuros, usar una variante negativa aprobada en lugar de invertir colores automáticamente.

## Paleta oficial y temas (resumen)

- **Marca:** Borgoña profundo (`#7A0F1F`), Carmesí (`#E63946`), Dorado (`#D4A23A`), Blanco cálido (`#FFFCFA`).
- **Light Mode:** Background `#FFFFFF`, Surface/Card `#F9FAFB`, Primary text `#0B0B0F`, Secondary text `#4B5563`, Border `#E5E7EB`.
- **Dark Mode (Carbón neutro):** Background `#18191D`, Surface/Card `#25272D`, Elevated surface `#30333A`, Border `#3B3E46`, Primary text `#F5F5F5`, Secondary text `#C4C6CC`.
- **Tipografía:** `Manrope` (Bold 700 / SemiBold 600) para marca y encabezados; `Inter` (Regular 400 / Medium 500) para lectura y contenido.

Para ver los tokens completos, colores semánticos y la estructura recomendada en Flutter (`lib/core/theme/` y `assets/branding/`), consulta [Guia_Identidad_Visual_Becify.pdf](./Guia_Identidad_Visual_Becify.pdf).
